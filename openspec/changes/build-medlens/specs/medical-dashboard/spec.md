## Purpose

Displays the structured medical record, timeline, report comparisons, and source viewing side-by-side in a professional dashboard.

## ADDED Requirements

### Requirement: Medical Dashboard
The system SHALL display extracted and patient-provided data, a medical timeline, and allow users to view side-by-side source documents for extracted facts.

#### Scenario: User views extracted lab value
- **WHEN** a user clicks on an extracted lab value in the dashboard
- **THEN** the system opens a side-by-side view highlighting the source document page from which the value was extracted.
